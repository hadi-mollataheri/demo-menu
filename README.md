## Features

- Browse products by category
- Search and filter products
- Product detail modal
- Cart with localStorage persistence
- Checkout form with dynamic delivery options
- Three simulated payment methods

## Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Vite (build tool only — output is plain HTML/CSS/JS)

## Run Locally

```bash
npm install
npm run dev
```
